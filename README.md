# رحلات مُطابق — عرض تعريفي

عرض تقديمي ثابت (HTML) يشرح **مُطابق**: منصة الجاهزية والامتثال الرقمي الحكومي.
٢١ شريحة، عربي RTL، مبنية على ألوان نظام التصميم الحكومي «كود المنصات».

**العرض مباشر:** https://ayadesignstudio.github.io/mutabiq-rehlat/

## التنقل

| المفتاح | النتيجة |
|---|---|
| ← أو مسافة | التالي (العرض RTL، فاليسار للأمام) |
| → | السابق |
| `F` | ملء الشاشة |
| السحب / عجلة الماوس | تنقّل |
| `#12` في آخر الرابط | الذهاب لشريحة بعينها |

الطباعة إلى PDF مضبوطة: شريحة واحدة لكل صفحة أفقية (٢٩٧×١٦٧ ملم).

## المحتويات

```
index.html      العرض كامل — لا يعتمد على أي مكتبة خارجية عدا الخط
shots/          أربع لقطات حقيقية من المنصة والإضافة
robots.txt      يمنع الفهرسة — العرض غير مُدرج في محركات البحث
.nojekyll       يعطّل معالجة Jekyll في GitHub Pages
```

لقطات الشاشة حقيقية من فحوصات فعلية، وهوية الجهة والموقع محجوبة عمدًا.
